# WMS (Website Monitoring System) — User Manual

Live: [https://leekimteck.kolejsynergy.com/wms/](https://leekimteck.kolejsynergy.com/wms/)  
GitHub: [https://github.com/jindeli71-maker/wms](https://github.com/jindeli71-maker/wms)

## What it does

Watches websites: up/down status, login-protected dashboard, password reset.

## Sign in

1. Open the live URL.
2. Enter **Username** and **Password**.
3. Click **Log In**.
4. Use **Forgot your password?** if you are locked out.

## Typical tasks

- Add a URL to monitor.
- Set how often to check it.
- Read uptime / downtime history.
- Turn off alerts for a site under maintenance.

## Tips

- Monitor the public homepage, not a page that needs login, unless the checker supports it.
- Keep alert email/Telegram details up to date.
